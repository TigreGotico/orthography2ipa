## Overview

The notes of the spec file open with these words:

> Cantabrian Spanish (Montañés). Northern conservative dialect with Asturleonese substrate. Apico-alveolar [s̺] (northern type), distinción (lleísmo/yeísmo distinction) preserved. Partial yeísmo: /ʎ/ preserved in older speakers, merged with /j/ in younger speakers.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 3 works, from 1994 to 2005. [Sources](#sources) lists them. The spec file writes 1 of the 61 spellings of its letter table and takes the other 60 from [Castilian Spanish](es-ES.md) `es-ES`.

The [spec file](../../orthography2ipa/data/es-ES-x-cantabri.json) holds the full notes, with the caveats of the spec.
