## Overview

The notes of the spec file open with these words:

> Egyptian Arabic, Cairene (مصري, the prestige urban koine and most widely understood Arabic dialect via film/TV).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 5 works, from 1956 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes 33 of the 258 spellings of its letter table and takes the other 225 from [Proto-Mashriqi Arabic](ar-x-mashriqi.md) `ar-x-mashriqi`.

The [spec file](../../orthography2ipa/data/arz-EG.json) holds the full notes, with the caveats of the spec.
