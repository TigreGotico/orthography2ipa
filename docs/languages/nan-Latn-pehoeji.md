## Overview

The notes of the spec file open with these words:

> Pe̍h-ōe-jī (POJ, 'vernacular writing', also called Church Romanization), the 19th-century missionary-developed Latin romanization of Southern Min / Hokkien, still in active use for Taiwanese Hokkien and Amoy Hokkien alongside the newer, near-identical official Tâi-lô standard (Ministry of Education, Taiwan, 2006).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 5 works, from 1987 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 38 spellings of its letter table itself.
