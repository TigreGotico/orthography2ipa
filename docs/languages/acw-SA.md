## Overview

The notes of the spec file open with these words:

> Hejazi Arabic (حجازي), urban western Saudi Arabia: Mecca, Medina, Jeddah. References Omar (1975) and Abdoh (2010).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 15 works, from 1975 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes 54 of the 259 spellings of its letter table and takes the other 205 from [Proto-Peninsular Arabic](ar-x-peninsul.md) `ar-x-peninsul`.

The [spec file](../../orthography2ipa/data/acw-SA.json) holds the full notes, with the caveats of the spec.
