## Overview

The notes of the spec file open with these words:

> Aromanian (Armâneashce/Vlach), Eastern Romance language spoken by the Aromanians in the Balkans (Greece, Albania, North Macedonia, Bulgaria, Serbia). Closely related to Romanian. Central vowel â/î = /ɨ/. Reduced /ə/ vowel ă. No official standardized orthography in most countries.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 1 work, from 2024. [Sources](#sources) lists them. The spec file writes all 34 spellings of its letter table itself.
