## Overview

The notes of the spec file open with these words:

> Tumbuka (chiTumbuka), Bantu N.21, Malawi and Zambia. Latin orthography: <b> and <d> are implosives /ɓ ɗ/, <ŵ> is the bilabial fricative /β/ (a distinctive Tumbuka letter), <c> = /tʃ/, <j> = /dʒ/, <l> and <r> are allographs of one flap phoneme /ɽ/, <ng'> = /ŋ/ vs <ng> = prenasalised /ŋɡ/.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 1952 to 2024. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 28 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/tum.json) holds the full notes, with the caveats of the spec.
