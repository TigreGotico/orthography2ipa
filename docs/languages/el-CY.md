## Overview

The notes of the spec file open with these words:

> Cypriot Greek (Κυπριακή διάλεκτος), dialect of Modern Greek spoken in Cyprus. Preserves features of medieval Greek. Notable features: geminate consonants preserved (e.g., γράμμα /ˈɡramːa/), distinct treatment of palatalization. Turkish loanwords. Uses standard Greek orthography.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 1 work, from 2024. [Sources](#sources) lists them. The spec file writes all 80 spellings of its letter table itself.
