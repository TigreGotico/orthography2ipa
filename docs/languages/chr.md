## Overview

The notes of the spec file open with these words:

> Cherokee (ᏣᎳᎩ ᎦᏬᏂᎯᏍᏗ, Tsalagi Gawonihisdi), the only Southern Iroquoian language. Written in the syllabary devised by Sequoyah (completed 1821): 85 characters, plus the later addition Ᏽ (mv), so 86 grapheme keys here, each character stands for a CV syllable (plus six bare vowels and the coda character Ꮝ /s/).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 2015 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 86 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/chr.json) holds the full notes, with the caveats of the spec.
