## Overview

The notes of the spec file open with these words:

> Serer (Seereer-Siin), Northern Atlantic (Senegambian) branch of Atlantic-Congo, spoken mainly in the Sine-Saloum region of Senegal. The 2005-standardized Latin orthography is close to phonemic: ⟨c⟩ = palatal stop /c/, ⟨j⟩ = /ɟ/ (as in the closely related Wolof), ⟨ñ⟩ = /ɲ/, ⟨ŋ⟩ = /ŋ/, ⟨y⟩ = /j/.
