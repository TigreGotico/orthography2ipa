## Overview

The notes of the spec file open with these words:

> Nigerian Arabic, locally Shuwa Arabic (Kanuri shuwa 'Arab nomad', ISO shu). Spoken in Borno and Yobe states (NE Nigeria), with continua into Cameroon and Niger.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 8 works, from 1968 to 2026. [Sources](#sources) lists them. The spec file writes 33 of the 252 spellings of its letter table and takes the other 219 from [Chadian Arabic](shu-TD.md) `shu-TD`.

The [spec file](../../orthography2ipa/data/shu-NG.json) holds the full notes, with the caveats of the spec.
