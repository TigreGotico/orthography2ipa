## Overview

The notes of the spec file open with these words:

> Latgalian (latgaļu volūda), an Eastern Baltic variety of Latvia recognised as a protected historic variant of Latvian, treated as a separate language by ISO 639-3 (ltg) and Glottolog.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 2011 to 2024. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 37 spellings of its letter table itself.
