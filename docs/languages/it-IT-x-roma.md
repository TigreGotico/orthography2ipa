## Overview

The notes of the spec file open with these words:

> Romanesco (Roman dialect). Central Italian of Rome and Lazio. Historically distinct from Tuscan, but re-Tuscanised from the 15th century onward due to the Papal court. Key features: (1) NO gorgia. (2) Rhotacism: /l/ → [r] before consonants (alto → [ˈarto]). (3) -ND- → [nː], -MB- → [mː].

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold.
