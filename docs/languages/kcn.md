## Overview

The notes of the spec file open with these words:

> Ki-Nubi / Nubi (ISO 639-3: kcn, Glottolog nubi1253), an Arabic-based creole spoken by the Nubi community of Uganda and Kenya (and diaspora in the DR Congo), the East African offshoot of the same 19th-century southern-Sudanese pidgin that gave rise to Juba Arabic.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 1997 to 2013. [Sources](#sources) lists them. The spec file writes all 34 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/kcn.json) holds the full notes, with the caveats of the spec.
