## Overview

The notes of the spec file open with these words:

> Guadramilese (guadramilés). SUB-ZONE DIPHTHONG NOTE (from Frías-Conde, El Habla de Sanabria, p. 3): The Guadramil sub-zone (Portuguese side) shows more extreme /wo/ diphthongization than the Spanish-side Sanabrian varieties: *cuorpo* (corpo), *cuarda* (corda), *muarto* (morto).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 5 works, from 1900 to 2005. [Sources](#sources) lists them. The spec file writes no spelling of its own. It takes all 78 from [Rionorese](ast-PT-x-rionor.md) `ast-PT-x-rionor`.

The [spec file](../../orthography2ipa/data/ast-PT-x-guadrami.json) holds the full notes, with the caveats of the spec.
