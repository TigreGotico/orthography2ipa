## Overview

The notes of the spec file open with these words:

> Libyan Arabic, baseline = the urban koine of Tripoli (Tripolitania) described by Pereira (2010, 2011 EALL 'Tripoli Arabic').

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 6 works, from 1984 to 2020. [Sources](#sources) lists them. The spec file writes 37 of the 255 spellings of its letter table and takes the other 218 from [Proto-Maghrebi Arabic](ar-x-maghrebi.md) `ar-x-maghrebi`.

The [spec file](../../orthography2ipa/data/ar-LY.json) holds the full notes, with the caveats of the spec.
