## Overview

The notes of the spec file open with these words:

> Dakota (Dakȟótiyapi), Siouan (Dakotan branch, sister to Lakota). Five oral vowels /a e i o u/ and three nasal vowels /ã ĩ ũ/, written with the tilde.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 1893 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 41 spellings of its letter table itself.
