## Overview

The notes of the spec file open with these words:

> Iñupiaq (Iñupiatun), Inuit language of northern Alaska. Latin orthography (Webster, Zibell, 1970s), the values above follow the North Slope dialect. Three vowel qualities /a i u/, each with a long counterpart written double (aa, ii, uu) and therefore derivable from the single-vowel mapping.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 1981 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 24 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/ik.json) holds the full notes, with the caveats of the spec.
