## Overview

The notes of the spec file open with these words:

> Juba Arabic / Árabi Júba (ISO 639-3: pga, Glottolog South Sudanese Creole Arabic, suda1237), an Arabic-based pidgin-creole, the lingua franca of Juba and much of South Sudan (est. hundreds of thousands of L1 and several million L2 speakers).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 1997 to 2017. [Sources](#sources) lists them. The spec file writes all 34 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/pga.json) holds the full notes, with the caveats of the spec.
