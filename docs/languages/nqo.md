## Overview

The notes of the spec file open with these words:

> N'Ko (ߒߞߏ), the Manding literary koiné written in the N'Ko script devised by Solomana Kanté in 1949. INPUT CONTRACT: native N'Ko-script text (Unicode block U+07C0..U+07FF, NFC), written RIGHT-TO-LEFT, no romanisation is accepted.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 2012 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 40 spellings of its letter table itself.
