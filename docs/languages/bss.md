## Overview

The notes of the spec file open with these words:

> Akoose (Akɔɔse, Bakossi), Northwest Narrow Bantu (Guthrie A.15) of the Kupe-Mwanenguba Division (South West Region) and Mungo Division (Littoral Region), Cameroon, c. 100,000+ speakers (Hedinger & Hedinger 1977, Hedinger 2016, A Grammar of Akoose, SIL/UT Arlington).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 1977 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 40 spellings of its letter table itself.
