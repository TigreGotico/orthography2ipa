# Limburgish (`li`)

<!-- atlas:summary begin -->
Limburgish is a Germanic language, written in the Latin script. Glottolog places it in Belgium, Germany and Netherlands. The `li` spec is at the research tier. It cites 14 sources and has 1 scored dataset.

## Overview

The notes of the spec file open with these words:

> Limburgish (Limburgs), West Germanic (Low Franconian) of the Meuse-Rhenish area.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 14 works, from 1976 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 120 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/li.json) holds the full notes, with the caveats of the spec.
