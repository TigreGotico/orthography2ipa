> Nuosu / Sichuan Yi (ꆇꉙ), a Loloish (Ngwi) language of Liangshan, written in the Modern Yi script (Liangshan Standard Yi, ratified 1980). INPUT CONTRACT: native Yi-syllabary text (Unicode Yi Syllables block U+A000..U+A4C6, NFC), the official Yi Pinyin romanisation is NOT accepted as input.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold.
