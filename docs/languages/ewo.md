## Overview

The notes of the spec file open with these words:

> Ewondo (Beti, Kolo), Bantu A.72 of the Beti-Fang cluster, spoken in the forests south of the Sanaga river across the Centre, East and Littoral regions of Cameroon, historically the Beti people's lingua franca and a former colonial mission/school language.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 1978 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 37 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/ewo.json) holds the full notes, with the caveats of the spec.
