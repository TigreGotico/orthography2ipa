## Overview

The notes of the spec file open with these words:

> Dinka (Thuɔŋjäŋ), Western Nilotic language of South Sudan. INPUT CONTRACT: the standard South Sudanese Dinka Latin orthography (the Rek-based standard written variety, descended from the alphabet adopted at the 1928 Rejaf Language Conference and shared across the Dinka dialects).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 5 works, from 1928 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 46 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/din.json) holds the full notes, with the caveats of the spec.
