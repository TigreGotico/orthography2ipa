# Murui Huitoto (`huu`)

<!-- atlas:summary begin -->

## Overview

The notes of the spec file open with these words:

> Huitotoan language (Murui/Bue) of Colombia and Peru, with an orthography and phonology drawn from Wojtylak's descriptive grammar. Six vowel qualities each contrast for length (written doubled), ɨ is a high back unrounded vowel.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 2 works, from 2024. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 30 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/huu.json) holds the full notes, with the caveats of the spec.
