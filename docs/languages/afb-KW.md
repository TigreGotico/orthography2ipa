## Overview

The notes of the spec file open with these words:

> Kuwaiti Arabic, the best-documented Gulf variety. Inherits the Gulf features: *q → [ɡ] (with [q] a formal/MSA candidate), velar affrication /k/→[tʃ] and /ɡ/→[dʒ] before high front /i, iː/, interdentals /θ ð ðˤ/ retained.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 2 works, from 2016 to 2026. [Sources](#sources) lists them. The spec file writes no spelling of its own. It takes all 261 from [Proto-Gulf Arabic](afb.md) `afb`.

The [spec file](../../orthography2ipa/data/afb-KW.json) holds the full notes, with the caveats of the spec.
