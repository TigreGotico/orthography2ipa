# Akan (Twi-Fante) (`ak`)

## Overview

The notes of the spec file open with these words:

> Akan, Asante Twi standard. INPUT CONTRACT: text is assumed to be in the unified Latin Akan orthography (Akan Orthography Committee / Bureau of Ghana Languages), i.e. the 22 Latin letters plus ⟨ɛ⟩ (U+025B) and ⟨ɔ⟩ (U+0254), with the digraphs ky, gy, hy, ny, ng, kw, gw, hw, tw, dw, nw.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 1978 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 33 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/ak.json) holds the full notes, with the caveats of the spec.
