## Overview

The notes of the spec file open with these words:

> Omani Arabic, a conservative Peninsular variety of the southeastern coast, genetically Peninsular (inherits ar-x-peninsul DIRECTLY, not the Gulf node).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 2 works, from 2016 to 2026. [Sources](#sources) lists them. The spec file writes 34 of the 247 spellings of its letter table and takes the other 213 from [Proto-Peninsular Arabic](ar-x-peninsul.md) `ar-x-peninsul`.

The [spec file](../../orthography2ipa/data/acx-OM.json) holds the full notes, with the caveats of the spec.
