## Overview

The notes of the spec file open with these words:

> Mingrelian (მარგალური ნინა), a Kartvelian (South Caucasian) language of western Georgia. INPUT CONTRACT: Georgian MKHEDRULI text (Unicode U+10D0..U+10FA, NFC), the historical Asomtavruli and Nuskhuri scripts and any romanisation are out of scope.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 5 works, from 1991 to 2026. 4 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 36 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/xmf.json) holds the full notes, with the caveats of the spec.
