## Overview

The notes of the spec file open with these words:

> Zamboangueño Chavacano, a Spanish-lexifier creole of the Philippines, written with the Spanish alphabet. Seseo throughout (⟨c⟩ before e/i, ⟨z⟩ = /s/, no /θ/), ⟨j⟩ and ⟨g⟩ before e/i = /h/~/x/, yeísmo (⟨ll⟩ = /j/, ʎ conservative), ⟨v⟩ = /b/.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 1972 to 2024. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 37 spellings of its letter table itself.

## Sources

The spec cites 4 works. 3 of them have a DOI or a URL. The spec file holds a note on what 3 of them support.

1. <a id="src-chavacano_wiki"></a>Wikipedia contributors (2024). *Chavacano*. Wikipedia. Cited: Alphabet, seseo, non-lenition of intervocalic /b d ɡ/, yeísmo. [en.wikipedia.org](https://en.wikipedia.org/wiki/Chavacano)
2. <a id="src-lipski1987"></a>Lipski, John M. (1987). *Modern Spanish once-removed in Philippine creole Spanish: the case of Zamboangueño*. Language in Society 16(1), pp. 91-108. Cited: pp. 93-99: seseo throughout, no /θ/, ⟨j⟩ and ⟨g⟩ before front vowels realised [h], yeísmo (⟨ll⟩ = [j]), ⟨v⟩ = [b], non-lenition of intervocalic /b d ɡ/ (retained stops, unlike peninsular Spanish). [jstor.org](https://www.jstor.org/stable/4167859)
3. <a id="src-forman1972"></a>Forman, Michael L. (1972). *Zamboangueño texts with grammatical analysis: a study of Philippine Creole Spanish*. PhD dissertation, Cornell University. Cited: Ch. 2 (phonology): five-vowel system /a e i o u/, preverbal TMA particles ya (perfective), ta (imperfective/progressive), ay~hay (future/irrealis), negation with no.
4. <a id="src-lipski2001"></a>Lipski, John M. (2001). *The place of Chabacano in the Philippine linguistic identity*. Estudios de Sociolingüística 2(2). Cited: Zamboangueño as the largest and most vital Chabacano variety, lexicon predominantly Spanish with Philippine (Cebuano/Hiligaynon/Tagalog) substrate morphosyntax. [personal.psu.edu](https://www.personal.psu.edu/jml34/chabacan.pdf)
