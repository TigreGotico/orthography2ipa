## Overview

The notes of the spec file open with these words:

> Basaa (Ɓasaá), Bantu A.43a (Guthrie), spoken by c. 300,000 people in the South, Centre and Littoral regions of Cameroon (Hyman, Basaa chapter, Hartell 1993, Alphabets of Africa). Latin orthography with African-reference-alphabet letters ɓ ɛ ŋ ɔ and ten multigraphs gw hy mb nj ny nd ŋg ŋgw ŋw kw.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 1993 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 42 spellings of its letter table itself.
