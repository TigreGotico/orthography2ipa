## Overview

The notes of the spec file open with these words:

> Nheengatu (nheẽgatú, 'Modern Tupí' / Amazonian General Language), a Tupí-Guaraní (Tupian) language of the upper Rio Negro, Brazil, Colombia and Venezuela.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 1994 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 31 spellings of its letter table itself.
