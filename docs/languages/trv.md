## Overview

The notes of the spec file open with these words:

> Seediq (Kari Seediq), including the Truku/Taroko variety that ISO 639-3 trv names, a Formosan (Austronesian) language of Taiwan.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 2005 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 25 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/trv.json) holds the full notes, with the caveats of the spec.
