## Overview

The notes of the spec file open with these words:

> Soninke (Serakhulle, Sarakolé), Soninke-Bozo branch of Mande, spoken by ~2.3 million people mostly in Mali and Mauritania, with communities across Senegal, Gambia, Guinea, Guinea-Bissau, Ivory Coast and Burkina Faso.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 2016 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 34 spellings of its letter table itself.
