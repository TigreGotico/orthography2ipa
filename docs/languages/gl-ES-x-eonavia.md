## Overview

The notes of the spec file open with these words:

> Eonavian (eonaviego, gallego-asturiano, fala del Navia-Eo), the Galician-Portuguese transitional speech of the Navia-Eo comarca in westernmost Asturias (Spain), between the río Eo (border with Galicia) and the río Navia.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 5 works, from 1990 to 2025. [Sources](#sources) lists them. The spec file writes 12 of the 72 spellings of its letter table and takes the other 60 from [Galician](gl-ES.md) `gl-ES`.

The [spec file](../../orthography2ipa/data/gl-ES-x-eonavia.json) holds the full notes, with the caveats of the spec.
