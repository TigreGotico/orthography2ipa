## Overview

The notes of the spec file open with these words:

> Aja (Adja, Ajagbe), a Gbe (Kwa) language of the Togo-Benin border region around the Mono River, closely related to Ewe, Gen and Fon. Africa-Alphabet-derived Latin orthography (introduced 1960s, revised 1970s): ɖ ƒ ɣ ŋ ɔ ɛ ʋ plus digraphs gb kp ny.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 2011 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 32 spellings of its letter table itself.
