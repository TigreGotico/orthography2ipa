## Overview

The notes of the spec file open with these words:

> Emilian-Romagnol (emiliàn e rumagnòl), a Gallo-Italic group of northern Italy. COMMITMENT: this map implements ONE variety and ONE norm, BOLOGNESE (Emilian side) written in the Ortografia Lessicografica Moderna (OLM) of Vitali & Lepri.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 4 works, from 2007 to 2026. 3 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 38 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/eml.json) holds the full notes, with the caveats of the spec.
