## Overview

The notes of the spec file open with these words:

> Luba-Kasai (Tshiluba/Ciluba), Guthrie L.31, Bantu language of Kasai region, DR Congo, one of the country's four national languages. Five-vowel system a/e/i/o/u with a length distinction. Standard orthography uses the digraphs ng, ny and sh but no q, r, x.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold.
