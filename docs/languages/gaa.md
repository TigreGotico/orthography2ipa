## Overview

The notes of the spec file open with these words:

> Ga (Gã), a Ga-Dangme (Kwa) language of the Greater Accra Region, Ghana. Latin-based orthography of 26 letters plus ŋ, ɛ, ɔ (Africa Alphabet extensions).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 1999 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 35 spellings of its letter table itself.
