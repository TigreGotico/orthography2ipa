# Khumi Chin (`cnk`)

## Overview

> Khumi Chin (Khumi, Khimi) is a South-Central Tibeto-Burman (Kuki-Chin) language of southern Chin State, Myanmar and the Chittagong Hill Tracts, Bangladesh.
