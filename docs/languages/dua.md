## Overview

The notes of the spec file open with these words:

> Duala, Bantu Sawabantu (A.24, Guthrie), lingua franca of the Duala and Mungo peoples of Cameroon's Littoral coast, first written 1870 by Alfred Saker (Baptist missionary Bible translation), with the modern General Alphabet of Cameroon Languages (AGLC, 1978) standardising it alongside other Cameroonian languages (Paulian 1971, Ittmann 1939).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 1939 to 2026. 1 of them is a Wikipedia article. [Sources](#sources) lists them. The spec file writes all 34 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/dua.json) holds the full notes, with the caveats of the spec.
