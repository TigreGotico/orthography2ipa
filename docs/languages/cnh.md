## Overview

The notes of the spec file open with these words:

> Hakha Chin (Lai, Baibum), spoken in Chin State, Myanmar and diaspora (Indianapolis, Ottawa). Central Kuki-Chin branch, Sino-Tibetan. Latin-based 'Hakha alphabet' orthography, a Mon-Burmese-based alternative script also exists but Latin is primary (Wikipedia, Peterson 2003).

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 3 works, from 2003 to 2012. [Sources](#sources) lists them.
