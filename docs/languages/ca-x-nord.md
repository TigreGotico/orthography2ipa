## Overview

The notes of the spec file open with these words:

> NORTHERN CATALAN (rossellonès/septentrional), Pyrénées-Orientales, France. Eastern block, descending from Old Catalan (ca-x-medieval) rather than from the Barcelona standard.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 9 works, from 1982 to 2026. 2 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes 4 of the 50 spellings of its letter table and takes the other 46 from [Old Catalan](https://tigregotico.github.io/orthography2ipa/#ca-x-medieval) `ca-x-medieval`.
