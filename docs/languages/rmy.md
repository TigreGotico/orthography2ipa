## Overview

The notes of the spec file open with these words:

> Vlax Romani, the largest Romani dialect subgroup after Balkan Romani (Northern Vlax: Kalderash, Lovari, Southern Vlax). Named for the Romanian-speaking principalities (Wallachia/Moldavia = 'Vlach' lands) where its speakers were historically enslaved, hence the strong Romanian adstrate.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 2 works, from 2002 to 2026. [Sources](#sources) lists them. The spec file writes no spelling of its own. It takes all 40 from [Romani](rom.md) `rom`.
