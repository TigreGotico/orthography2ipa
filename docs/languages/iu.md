# Inuktitut (`iu`)

<!-- atlas:summary begin -->
Inuktitut is an Eskimo-Aleut language, written in the Canadian Aboriginal Syllabics script. Glottolog places it in the Eurasia and North America macroareas. The `iu` spec is at the research tier. It cites 6 sources and has 0 scored datasets.

## Overview

The notes of the spec file open with these words:

> Inuktitut (ᐃᓄᒃᑎᑐᑦ). INPUT CONTRACT: qaniujaaqpait, Inuktitut syllabics (Unified Canadian Aboriginal Syllabics, U+1400..U+167F, NFC). The Latin orthography qaliujaaqpait (Inuujingajut) is a separate input and is NOT covered by this map.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. No board row scores it yet, so the measured gold of that tier is still missing. It cites 6 works, from 2024 to 2026. 4 of them are Wikipedia articles. [Sources](#sources) lists them. The spec file writes all 135 spellings of its letter table itself.

The [spec file](../../orthography2ipa/data/iu.json) holds the full notes, with the caveats of the spec.
