## Overview

The notes of the spec file open with these words:

> Rijāl Almaʿ Arabic (رجال ألمع), a sedentary dialect of the ʿAsīr / Saudi Tihāmah in southwestern Saudi Arabia.

The spec is at the [research](../specs/quality_tiers.md#research) tier, which asks for a cited description, with stress and a measured gold. It cites 8 works, from 2002 to 2025. [Sources](#sources) lists them. The spec file writes 21 of the 247 spellings of its letter table and takes the other 226 from [Proto-Peninsular Arabic](ar-x-peninsul.md) `ar-x-peninsul`.

The [spec file](../../orthography2ipa/data/ar-SA-x-rijal-alma.json) holds the full notes, with the caveats of the spec.
